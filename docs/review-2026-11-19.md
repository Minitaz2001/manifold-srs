## Single-reviewer, high value

- **UTC day bug ✓ (FS):** ts-fsrs computes elapsed_days on UTC dates; a learning session crossing 00:00 UTC (4 pm PST / 7 pm EST) gets the long-term formula → 3.5x stability error on first graduation. Fix: shift the clock into ts-fsrs by tz offset − rollover hour.
- **Review due by timestamp, not day (FS):** reviewed 22:00 with 1-day interval = invisible at 08:00. Add 4 am rollover; review-state due if due < next rollover.
- **Replay diverges (FS):** replays with current retention, unsuspends unlogged, `prev` from closure (double-tap race). Enable fuzz (verified deterministic ✓).
- **Live readout defeats the drill (LS):** while dragging, the value (+ log) is shown, so a learned fact becomes "drag until the number matches". Hide until Confirm.
- **Window is guessable ✓ (LS):** truth always 25-75% and always between the first two anchors; centre-tap with zero knowledge passes ~60%, Good ~30%. Fade anchors / widen with stability; sometimes one-sided anchors; some windows should straddle million/billion.
- **No undo / bury / suspend / flag on review screen (CD):** reveal button sits where grade buttons appear → double-tap mis-grades.
- **Self-grading after reveal is hindsight-biased (LS):** optional unscored "guess the exponent" tap before reveal; hypercorrection benefit.
- **Ratio probes rare for months (LS):** gated on drill stability ≥21 d, 1/session, nearest option position tell (RatioProbeWidget.tsx:46). Add never-taught transfer probes.
- **Show signed bias at reveal (LS):** "you run 2.1x high on GDP".
